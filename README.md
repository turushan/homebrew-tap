# turushan/tap

Homebrew tap for apps by Turushan Aktay.

## Codex Whip

A menu bar app that gets Codex CLI working again after capacity errors and quota waits.
Signed and notarized by Apple. [codexwhip.com](https://codexwhip.com)

```sh
brew install --cask turushan/tap/codex-whip
```

Codex Whip updates itself, so `brew upgrade` leaves it alone. `brew uninstall --cask codex-whip`
removes the app; add `--zap` to also remove its settings and history.

The cask is updated with every [Codex Whip release](https://github.com/turushan/codex-whip/releases).
